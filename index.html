Твой сайт - мой код

Кто я?

Я начинающий веб разработчик.Пишу сайты с нуля в VS Code. Люблю работать с кодом напрямую: без шаблонов и рамок — так можно воплотить самые смелые идеи в жизнь.

Мои навыки

  • HTML5 / CSS3 — чистая вёрстка, семантика, доступность
  • Адаптив — правильное отображение на разных устройствах
  • Работа в VS Code — без конструкторов, только код
  • Базовые JS — интерактив, простые скрипты
  • Git — коммиты, ветки, аккуратная история изменений

Мой подход к работе

Перед началом работы я придерживаюсь собственных правил — так меньше сюрпризов в середине проекта.

  • Разбить сайт на блоки: разделить всю смысловую часть и оформить её отдельными секциями.
  • Продумать шапку сайта и логотип (если есть) — это сразу задаёт структуру.
  • Представить, как блоки будут располагаться на странице: набросать простую схему в голове или на бумаге.
  • Подумать про адаптацию: как сайт будет выглядеть на разных устройствах, где что перестроится.
  • Наметить интерактив: какие элементы должны реагировать на действия пользователя.
  • Начать с вёрстки: собрать основной текст и фото, чтобы видеть каркас.
  • Добавить стилистику и интерактив — довести до аккуратного вида.
  • Проверить на мобильном: убедиться, что всё встаёт ровно и ничего не ломается.
  • Сделать финальную вычитку: проверить отступы, шрифты и мелкие косяки, которые видно только в конце.
